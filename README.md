## Project Overview

This project is a mobile-first interactive birthday website designed as a digital love-letter experience.

It is intentionally structured as a sequence of interactive scenes rather than a conventional scrolling landing page.

The experience includes:

- PIN opening screen
- cinematic opening
- birthday message
- interactive CSS 3D gift box
- personal letter
- real-time Indonesia/Japan clocks
- 8 portrait memories
- animated love-thread heart
- interactive 3D CSS birthday cake
- animated candles
- optional microphone interaction
- wish release animation
- mathematics game
- Star Run mini-game
- Easy English game
- final birthday message
- replay functionality
- persistent music across scenes
- responsive mobile-first interface
- reduced-motion support
- code-generated decorative elements
